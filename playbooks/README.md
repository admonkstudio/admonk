# Admonk Playbooks

**Status:** Structure created; playbooks should be authored after the relevant doctrine/standards are approved.

Playbooks answer:

> **How should a person or agent perform this work?**

Potential domains:
- discovery;
- product definition;
- design;
- architecture;
- implementation;
- verification;
- release;
- operations.

AI may help draft procedures, but each playbook must be validated against authoritative sources and real project experience before it becomes canonical.

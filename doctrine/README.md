# Admonk Doctrine

**Status:** Structure created; foundational doctrine not yet populated.

This directory will contain human-approved, research-backed beliefs that govern how Admonk builds software products.

Doctrine answers:

> **What does Admonk believe, and why?**

## Planned areas

- product principles
- design principles
- engineering principles
- security principles
- AI autonomy principles
- operations principles

## Authority rule

AI may:
- research;
- compare;
- challenge;
- draft proposals;
- identify contradictions;
- maintain approved wording.

AI may not:
- silently create doctrine;
- promote research notes into doctrine;
- replace human judgment with generic best practices.

> **The repository structure is reusable. The doctrine must be earned.**

# Project Lifecycle Audit

Use this for an existing website/project, including Admonk's current site.

The goal is not to force the project back to the beginning.

The goal is to identify:

- what is already strong
- what is partial
- what is missing
- what conflicts
- what should be preserved
- what should happen next

Classification:

- **Complete**
- **Partial**
- **Missing**
- **Conflicting**
- **Not applicable**

Action type:

- **Keep**
- **Improve**
- **Replace**
- **Create**
- **Defer**

# Capability Map — Maturity Levels

**Status:** Research scaffold.

The purpose is to avoid requiring enterprise tooling for low-risk prototypes while still defining escalation paths.

## Candidate maturity model to research

### Level 0 — Exploration
Disposable/reversible experiments, no meaningful production dependency.

### Level 1 — Controlled Prototype
Small controlled user set, low blast radius, limited persistent/real data.

### Level 2 — Production
Real users/data, support responsibility, live integrations/actions.

### Level 3 — High-risk / High-scale
Material regulatory, financial, safety, security, scale or blast-radius consequences.

This model is provisional and must be reconciled with the existing Prototype / Production / High-risk governance model.

For each capability/tool, research:
- earliest maturity level where it becomes useful;
- earliest level where it becomes required;
- evidence that triggers escalation;
- cost/complexity of adoption;
- exit/deprecation condition.

# Admonk SEO

SEO supports the Web Experience. It must not turn pages into keyword-first content that damages clarity, brand voice, or user experience.

## Source of Truth

For search-engine behavior, verify current guidance against primary documentation, especially Google Search Central. Do not rely on stale SEO folklore.

## Core Review

Check when applicable:

- crawlability and indexability
- logical information architecture
- descriptive, stable URLs
- unique titles and useful descriptions
- heading/content hierarchy
- canonical strategy
- duplicate-content handling
- redirects and status codes
- robots directives
- XML sitemap coverage
- structured data that accurately represents real page content
- image discoverability/alt text where useful
- internal linking
- mobile rendering
- performance/Core Web Vitals
- localization/hreflang

## Migration / Redesign

Before replacing a live website:

1. inventory important existing URLs
2. identify pages gaining/losing/merging content
3. map old URLs to best new equivalents
4. preserve valuable content and internal-link relationships where appropriate
5. configure permanent redirects
6. verify canonicals, robots, sitemap and metadata
7. crawl/test the new environment before launch
8. monitor indexing/search data after launch

Never redirect every removed URL to the homepage simply to avoid 404s.

## Structured Data

Use schema only when it matches visible, real content and the entity/page type. Do not fabricate ratings, reviews, prices, organization details, or other structured facts.

## Content Rule

Write for the user's question and business objective first. Search visibility should improve useful content, not create filler.

## Verification

SEO work is incomplete until the rendered output is inspected: final HTML/head metadata, links, redirects, sitemap/robots behavior and structured data where applicable.

## Admonk Principle

> Search engines should understand the experience without forcing humans to read search-engine copy.

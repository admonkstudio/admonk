# Admonk Studio Foundation v1.0.0 — Release Notes

**Release date:** 2026-09-26  
**Status:** LOCKED  
**Product Supervisor included:** v2.0.0

## What this release establishes

Studio Foundation v1.0.0 is the first locked Admonk operating system for researching, defining, designing, building, verifying, releasing, operating and improving software products.

It includes:
- approved foundational doctrine (R001–R016);
- tool/capability decisions T017–T028;
- Studio Standards S001–S030;
- seven workflow playbooks PB01–PB07;
- Design Foundation Level-1 rules;
- reconciled reusable skills/templates;
- a deterministic source-of-truth/navigation model.

## Validation

**BriefFlow:** PASS  
Corrections learned from the small-product crash test:
- BF01 — require governance information, not a fixed number of Prototype files;
- BF02 — consequential approvals are action-bound and need no redundant second confirmation when the valid approval already covers the exact action.

**Marketing Hub:** PASS  
Correction learned from the serious discovery-stage product:
- MH01 — lifecycle and risk are separate. Lifecycle is Prototype/Production; independent risk overlays protect sensitive/high-consequence work at either stage.

**Repository contradiction/navigation audit:** PASS.

## Product Supervisor v2.0.0

The Supervisor moves from v1.1.0 to v2.0.0 because FOUNDATION-M1 introduced material governance-semantic changes:
- progressive Prototype artifact splitting;
- exact action-bound consequential approval;
- Prototype/Production lifecycle separated from risk overlays;
- revised exception semantics and Foundation routing.

## Locked rule

This release is a baseline, not a frozen forever doctrine.

Future evidence may justify change, but changes must be:
1. explicit;
2. researched proportionally when material;
3. recorded with accepted cost/tradeoff;
4. versioned rather than silently rewriting v1.0.0.
